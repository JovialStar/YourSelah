# Download Selah

Get the latest version from the **[Releases page](https://github.com/JovialStar/YourSelah/releases/latest)**. Pick the file for your computer:

| Your computer | File to download |
| --- | --- |
| Mac with Apple silicon (M1 or later) | `Selah_x.y.z_aarch64.dmg` |
| Mac with Intel | `Selah_x.y.z_x64.dmg` |
| Windows 10 or 11 | `Selah_x.y.z_x64-setup.exe` (or the `.msi`) |
| Linux | `.AppImage`, `.deb` (Debian/Ubuntu), or `.rpm` (Fedora) |

Not sure which Mac you have? Apple menu → About This Mac. "Chip: Apple M…" means Apple silicon.

## Installing

**Mac:** open the `.dmg` and drag Selah into Applications. The first time, right-click Selah → **Open** → **Open**.

**Windows:** run the installer. If Windows says "Windows protected your PC", choose **More info** → **Run anyway**.

**Linux:** make the AppImage executable (`chmod +x Selah*.AppImage`) and run it, or install the `.deb` or `.rpm`.

Until the app is code-signed, these one-time warnings are expected.

## Updates

Selah checks for a new version each time it opens. When one is available you'll see **Update available**; choose **Update now** and it installs and restarts.
